# heartbeat♡

내 음원을 넣으면 자동으로 채보를 만들어 주는 4키 리듬게임. 빌드 도구 없이 `index.html`을 열면 바로 실행됩니다.

솜사탕 드림코어 톤의 분홍 도트 디자인이고, 모바일 가로·세로 모두 대응합니다.

## 수록곡

| 곡 | 길이 |
|----|------|
| 恋のビート | 1:20 |
| 虹を越えて | 1:21 |

내 음원 파일을 직접 불러오거나, 다른 탭에서 재생 중인 소리를 녹음해 채보를 만들 수도 있습니다.

### 수록곡을 추가하려면

1. `songs/` 에 mp3를 넣습니다.
2. `js/songs.js` 의 `builtin` 배열에 항목을 추가합니다.
3. `python tools/embed-songs.py` 를 실행합니다.

3번이 필요한 이유: 브라우저는 `file://` 에서 `fetch()` 를 차단하므로, `index.html` 을 더블클릭해서 연 페이지는 `songs/*.mp3` 를 읽을 수 없습니다. 이 스크립트가 mp3를 base64로 `songs/tracks.js` 에 구워 넣어 그 제약을 우회합니다. 로컬 서버나 GitHub Pages처럼 http로 열면 mp3를 직접 fetch하므로 이 파일은 필요 없고, 그래서 git에는 포함하지 않습니다(약 5MB).

`js/songs.js` 의 길이 표기는 **디코딩된 실제 길이를 내림한 값**입니다. 게임 안의 상태줄도 같은 방식으로 표시하므로 둘이 어긋나지 않습니다(80.8초 → `1:20`). mp3 헤더의 비트레이트로 계산하면 VBR 파일에서 실제보다 몇 배 길게 나오니 쓰지 마세요.

## 플레이

`index.html`을 브라우저로 열고 — 수록곡을 고르거나, 내 음원을 불러오거나, 탭 소리를 녹음해서 시작하세요.

노트를 정확히 치면 레인마다 다른 음이 납니다. 네 레인은 펜타토닉(C5·E5·G5·B5)이라 동시에 눌러도 어울립니다.

## 유튜브 소리로 만들기

유튜브·사운드클라우드 **링크를 직접 넣는 방식은 브라우저만으로 불가능합니다.** 미디어가 교차 출처라 `fetch()`가 막히고, 임베드 플레이어의 소리는 iframe 안에 있어 Web Audio가 샘플을 읽지 못합니다.

대신 이 기기에서 **이미 재생 중인 소리를 녹음**합니다.

1. 유튜브를 다른 탭에서 열어 둡니다
2. **🎧 유튜브 소리로 만들기** 를 누릅니다
3. 공유 창에서 그 탭을 고르고 **"탭 오디오도 공유"를 체크**합니다 — 가장 흔한 실패 원인입니다
4. 곡을 처음부터 재생하고, 끝나면 **녹음 끝내기**를 누릅니다

크롬·엣지만 지원합니다(사파리는 탭 오디오 캡처가 없어 버튼이 숨겨집니다). 녹음한 만큼만 채보가 되고, 폭주 방지로 10분 상한이 있습니다.

- **키보드**: `D` `F` `J` `K`
- **모바일**: 화면 하단 4개 패드 터치
- **일시정지**: `Esc` 또는 우측 상단 버튼

## 자동 채보

음원을 4개 주파수 대역으로 나눠 오프라인 렌더링한 뒤, 각 대역의 에너지 변화에서 타격 지점(onset)을 찾아 레인에 배치합니다.

| 레인 | 대역 | 주로 잡히는 소리 |
|------|------|------------------|
| D | ~130Hz 저역 | 킥 드럼, 베이스 |
| F | 320Hz 중저역 | 스네어, 낮은 악기 |
| J | 1.4kHz 중고역 | 보컬, 멜로디 |
| K | 3.8kHz~ 고역 | 하이햇, 심벌 |

검출된 onset 중 **강한 순서대로** 난이도별 노트 예산이 찰 때까지 채우되, 같은 레인·전체 최소 간격 규칙을 만족하는 것만 채택합니다. 예산으로 먼저 자르고 간격으로 또 거르면 노트가 이중으로 손실되어 설정보다 훨씬 성겨집니다.

| 난이도 | 초당 노트 | 같은 레인 최소 간격 | 홀드 비율 | 최대 꼬리 | 홀드 중 다른 레인 |
|--------|-----------|---------------------|-----------|-----------|-------------------|
| EASY | 1.8 | 0.34s | 없음 | — | — |
| NORMAL | 3.0 | 0.22s | 12% | 1.6s | 안 나옴 |
| HARD | 5.0 | 0.13s | 20% | 2.6s | 나옴 |

체감 난이도를 가장 크게 좌우하는 건 노트 수가 아니라 마지막 열입니다. 꼬리를 누르고 있는 동안 다른 레인에 노트가 나오면, 한 손가락을 누른 채로 다른 손가락을 쳐야 합니다. 실제 리듬게임의 기법이지만 캐주얼한 채보에서는 그냥 엉망으로 느껴집니다. EASY·NORMAL은 `soloHold`를 켜서 홀드가 항상 단독으로 나오게 하고, HARD에서만 겹치도록 두었습니다.

실제 곡(恋のビート, 80.8초) 기준입니다:

| 난이도 | 노트 | 홀드 | 꼬리 중 다른 레인 노트 |
|--------|------|------|------------------------|
| EASY | 146 | 0 | 0 |
| NORMAL | 243 | 8 | **0** |
| HARD | 404 | 51 | 262 |

`soloHold`가 켜지면 홀드는 곡이 비는 자리에만 들어갈 수 있어서 개수가 확 줄어듭니다. 노트를 지우는 대신 꼬리가 들어갈 공간이 있는 곳만 고르는 방식이라, 밀도는 그대로 두고 홀드만 드물어집니다.

## 판정

노트 시각 기준 ±초 단위로 판정하고, 콤보가 쌓일수록 점수 배수가 붙습니다(최대 1.5배).

| 판정 | 허용 오차 | 점수 |
|------|-----------|------|
| PERFECT | 45ms | 300 |
| GREAT | 90ms | 200 |
| GOOD | 145ms | 100 |
| MISS | 190ms 초과 | 0 |

노트가 음악과 어긋나 보이면 메뉴의 **싱크 보정** 슬라이더로 맞추세요. 기기·브라우저마다 오디오 출력 지연이 다릅니다.

## 홀드 노트

꼬리가 달린 노트는 **꾸욱 누르고 있어야** 합니다. 머리는 일반 노트처럼 판정하고, 꼬리를 끝까지 유지하면 보너스 220점이 붙습니다. 도중에 놓으면 콤보가 끊기고 미스 하나가 기록됩니다(끝에서 130ms 이내는 봐줍니다).

누르고 있는 동안에는 레인마다 다른 음이 조용히 이어져서, 꼬리를 보지 않아도 유지 중인지 귀로 알 수 있습니다.

채보 생성기는 온셋 직후 해당 대역의 에너지가 얼마나 오래 유지되는지(`sustainAfter`)를 재고, 그 값이 긴 순서대로 난이도별 홀드 예산만큼 배정합니다. 꼬리 길이는 두 가지로 잘립니다:

- **같은 레인의 다음 노트**까지 (항상 적용)
- **모든 레인의 다음 노트**까지 (`soloHold`, EASY·NORMAL)

잘린 결과가 최소 길이(0.34초)에 못 미치면 홀드가 되지 않고 일반 노트로 남습니다.

## 타격음

노트를 치면 **실로폰 소리**가 납니다. 음원 파일이 아니라 합성인데, 판정 즉시 울려야 하는 소리라서 네트워크에서 받거나 그때 디코딩하면 지연이 가장 잘 들리는 지점에 지연이 생깁니다.

실로폰 음색은 세 겹입니다:

- **말렛 타격** — 3.5kHz 위만 남긴 2ms 노이즈. 이게 없으면 음이 "쳐진" 게 아니라 그냥 페이드인됩니다
- **기음** — 사인파, 0.4초에 걸쳐 잔향
- **3배음** — 실로폰 바는 첫 배음이 기음의 12도 위(3배)에 오도록 조율됩니다. 이 배음비와 빠른 감쇠(0.13초)가 실로폰다움을 만듭니다

레인은 장음계 펜타토닉(C5·E5·G5·C6)이라 어떤 조합을 동시에 쳐도 불협이 되지 않습니다. 홀드 유지음은 한 옥타브 아래에 두어 타격음과 음역이 겹치지 않게 했습니다.

소리가 너무 크거나 작으면 `js/audio.js` 의 `hitBus()` 게인과 `tap()` 의 `level` 값을 조절하세요.

## 구조

```
index.html            마크업 + 스크립트 태그
css/style.css         스타일 (가로/세로 반응형)
js/config.js          상수 · 공유 네임스페이스(RG)
js/dom.js             DOM 참조
js/icon.js            마스코트 픽셀 아트 → SVG · 파비콘
js/audio.js           오디오 컨텍스트 · 타격음 합성
js/capture.js         탭 오디오 녹음 → AudioBuffer
js/songs.js           수록곡 목록 · 로딩(base64 / fetch)
js/chart.js           주파수 분석 → 자동 채보
js/render.js          캔버스 크기 계산 · 그리기
js/game.js            판정 · 점수 · 프레임 루프 · 입력
js/ui.js              메뉴 · 설정 · 전체화면
js/main.js            부트스트랩
songs/                mp3 원본
tools/embed-songs.py  mp3 → base64 (file:// 대응)
tools/devserver.py    캐시 끈 로컬 서버 (개발용)
```

`import`/`export` 대신 일반 `<script>`와 전역 네임스페이스 `RG`를 씁니다. ES 모듈은 브라우저가 `file://`에서 로딩을 차단해서, 파일을 더블클릭해 여는 방식이 동작하지 않기 때문입니다. 스크립트 로드 순서는 의존성 순서이므로 `index.html`에서 순서를 바꾸면 안 됩니다.

## 구현 노트

- **타이밍은 `AudioContext.currentTime` 기준**입니다. `requestAnimationFrame` 타임스탬프로 판정하면 프레임이 밀릴 때 음악과 어긋납니다.
- **캔버스 레이아웃은 비율 기반**입니다. 키패드 높이는 화면의 19%(46~92px 제한)라서 가로모드에서도 노트 영역이 눌리지 않습니다.
- **탭이 화면 밖으로 나가도** 패드가 눌린 채 멈추지 않도록 `pointerup`을 `window`에서 받습니다.
- **다른 앱으로 전환하면 자동 일시정지**됩니다. 오디오와 판정 시계가 어긋나는 것을 막기 위함입니다.
- **`localStorage` 접근은 전부 `try/catch`** 안에 있습니다. 일부 `file://` 환경에서 접근이 차단되면 예외가 던져져 스크립트 전체가 죽습니다.

## 브라우저 요구사항

Web Audio API의 `OfflineAudioContext`와 Pointer Events를 씁니다. 최신 Chrome / Edge / Safari / Firefox에서 동작합니다. 모바일에서는 첫 탭이 있어야 오디오가 활성화됩니다.
